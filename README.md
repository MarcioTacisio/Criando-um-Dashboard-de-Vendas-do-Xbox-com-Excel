# Dashboard de Vendas do Xbox Game Pass

Dashboard feito no Excel com as vendas de assinaturas do Xbox Game Pass, usando dados fictícios de 2024.

## O que tem
- Faturamento dos planos anuais, com e sem renovação automática
- Total de vendas do EA Play Season Pass
- Total de vendas do Minecraft Season Pass
- Filtro por tipo de assinatura (mensal, trimestral ou anual)

## Como usar
Baixe e abra o arquivo `dashboard_xbox_traduzido.xlsx` no Excel. A aba visível é o Dashboard, e as abas de apoio (Assets, Bases e Cálculos) estão ocultas.

Feito com Excel (tabelas dinâmicas, gráfico e segmentação de dados).
